EMDR · Prueba de comunicación

Conexión por servidor

Esta versión experimental envía órdenes de control por WebSocket, sin usar canal retransmitido. El sonido permanece dentro del dispositivo del paciente.

La página está preparada, pero necesita un servidor de retransmisión desplegado. No hay ninguno contratado ni conectado todavía.

El servidor deberá admitir WebSocket seguro (wss://) y ejecutar el código del proyecto auditivo/relay/server.js.

EMDR · Estimulación auditiva bilateral

Disponible en ordenador

Para garantizar la alternancia entre el oído izquierdo y el derecho, esta versión está habilitada únicamente para ordenadores.

Abre el enlace desde un PC o Mac y conecta unos auriculares estéreo. La versión móvil está pendiente de revisión.
